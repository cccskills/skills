# 語尾カタログ（詳細）

人物の声を設計する時に引く辞書。SKILL.md の18型を土台に、役割語・時代語・方言・キャラ語尾まで、変なものも含めて並べる。

使い方：
- まず「1. 基本の18型」から、その人物の基本の語尾を1〜2個選ぶ。
- 出自・身分・時代・地域に理由があれば、「3〜6」から味付けを足す。
- 型1（言い切り）・型8（〜じゃ・〜のう）・型10（体言止め）は誇張表現なので、どの人物でも基本の語尾にしない。
- 語尾が他の人物と重なってもよい。書き分けは語尾ではなく、関心・反応・言わないことで付ける。
- 「記号性」は、その語尾がどれだけ「キャラの貼り紙」に見えるかの目安。★が多いほど一発で印象が付くが、多用すると冗談に見える。シリアスな人物には★★まで、★★★以上は理由のある時か、笑わせたい時だけ。

## 2. 文末を作る部品

語尾は「述語の形」＋「終助詞」＋「伸ばし・記号」の組み合わせでできている。部品ごとに選ぶと、型の中でも幅が出る。

|---|---|---|---|

### 2-3. 伸ばし・記号・表記

| 部品 | 例 | 印象 |
|---|---|---|
| 長音 | 行くよー／だなぁ | 幼さ、のんびり、甘え |
| 小さい「っ」 | 行きますっ／はいっ | 元気、緊張 |
| 小さい母音 | だよぉ／ですぅ | 甘え、ぶりっ子（★★★） |
| 「……」の後置 | 行く…… | 余韻、言い切れない |
| 「！」 | 行くぞ！ | 勢い。重ねると子どもっぽい |
| 「？」の上がり | 行くんだ？ | 皮肉、軽い驚き |
| 「♪」「☆」 | 行こっ♪ | 浮かれ、ギャグ（ゲーム・漫画で注意して使う） |
| カタカナ混じり | ワタシ、行きマス | 外国人、ロボット（★★★★、配慮が要る） |
| ひらがな多め | いっしょに、いこ | 幼い、ぼんやり |
| 漢字多め | 同行致す | 堅物、古風 |

## 4. 方言

実在の地域の言葉。ステレオタイプに寄りやすいので、使うなら地域を一つに決め、語尾だけでなく語彙・抑揚も揃える。ファンタジー世界では、特定の地域を思わせすぎない「なんとなく田舎」の崩し（型9）で足りることが多い。

| 北海道 | 〜だべ／〜っしょ | 〜ない | 〜から | なまら（とても）、〜さ | 明日、出発するっしょ | それ違うべさ |

- 一人の人物の中で、地域を混ぜない。
- 断定・否定・理由の三つを揃えると、それらしく聞こえる。語尾一つだけ方言にすると、作り物に見える。
- 方言は「素が出た瞬間」に使うと効く（普段は標準語、怒ると地元の言葉、など）。

## 5. 時代語（古い言い回し）

時代物・ファンタジーで「昔っぽさ」を出す部品。現代語と混ぜると浮く。

|---|---|---|

二人称：貴様（古くは敬称、今は罵倒）、貴殿、そなた、そち、お主、おぬし、汝、うぬ、お前さん、あんた、てめえ。

ファンタジーでの目安：
- 王・当主は 7（〜ぬ、〜せよ）を一つだけ。「ござる」「候」はほぼ使わない（和風に寄りすぎる）。
- 武人は「参る」「致す」程度に留めると、和風に寄らずに古風さが出る。
