# jp-business-mail

日本語のビジネスメールを書く、または直す。メールは送らない。文面を作って返すだけにする。

## 1. 最初に確かめること

足りないものだけを、まとめて 1 回で聞く。分かっているものは聞かない。

- **相手**: 社外か社内か。社外なら会社名・部署・氏名・役職。初めての連絡か、やりとりがあるか。
- **場面**: 依頼・お礼・お詫び・催促・断り・日程調整・報告・初めての連絡、のどれか。
- **伝えたいこと**: 用件、期限、相手にしてほしいこと。
- **差出人**: 会社名・部署・氏名（署名に使う）。

聞かずに書くときは、分からない所を `【〇〇】` の形で空けて渡す（例: `【先方のご担当者名】`）。

## 2. 文面の型

```
件名: 【用件が一目で分かる言葉】＋（会社名・氏名）

株式会社〇〇
営業部 部長 〇〇様

いつもお世話になっております。
株式会社△△の□□です。

（本題: 結論 → 理由・詳細 → 相手にしてほしいこと・期限）

（結び）

――――――――――
株式会社△△ 営業部
□□ □□
TEL / メール
――――――――――
```

- **件名**: 「ご相談」「お願い」だけにしない。何の件かを入れる（例: 「【ご確認のお願い】11月分お見積書の送付」）。返信では「Re:」を残し、件名は書き換えない。
- **宛名**: 会社名は「(株)」と略さず正式名称。「部長 〇〇様」とし、「〇〇部長様」としない。複数人なら「〇〇様、△△様」、部署宛てなら「〇〇部 御中」（「御中」と「様」は併用しない）。
- **挨拶**: 社外は「いつもお世話になっております。」、初めては「突然のご連絡失礼いたします。」、社内は「お疲れさまです。」。「ご苦労さまです」は目上に使わない。
- **本題**: 結論を先に書く。1 文は 60 字程度までにし、長ければ分ける。日付・金額・数量は箇条書きにする。
- **結び**: 場面に合わせる（下の「場面別」）。「取り急ぎ」は、後で改めて連絡するときだけ使う。

## 3. 敬語の点検

直すときは、次の誤りを探す。

| 誤り | 直し | 理由 |
| --- | --- | --- |
| おっしゃられる / ご覧になられる | おっしゃる / ご覧になる | 二重敬語 |
| お伺いさせていただきます | 伺います | 二重敬語＋「させていただく」の重複 |
| 拝見させていただきました | 拝見しました | 「拝見」で既に謙譲 |
| 了解しました / 了解です | 承知しました / かしこまりました | 目上・社外には「承知」 |
| よろしかったでしょうか | よろしいでしょうか | 過去形にする理由がない |
| 〜のほう、お送りします | 〜をお送りします | 「のほう」は不要 |
| 〜になります（「こちら資料になります」） | 〜です / 〜でございます | 変化していないのに「なる」 |
| 御社（メール） | 貴社 | 書き言葉は「貴社」、話し言葉は「御社」 |
| 参考になりました（目上へ） | 大変勉強になりました | 目上の話を「参考」にするのは失礼 |
| 弊社の〇〇部長が | 弊社の部長の〇〇が | 社外へは自社の人に敬称・役職を付けない |

**「させていただく」の多用**: 相手の許可や恩恵があるときだけ使う（「本日は欠席させていただきます」）。1 通に 2 回以上あれば、「いたします」「します」に置き換えられないか確かめる。

**クッション言葉**: 依頼・断り・指摘の前に 1 つだけ置く。「恐れ入りますが」「お手数ですが」「あいにく」「差し支えなければ」。毎文に付けると読みにくい。

## 4. 場面別

| 場面 | 本題で書くこと | 結び |
| --- | --- | --- |
| 依頼 | 何を・いつまでに・なぜ。相手の手間を減らす情報（添付・URL） | お忙しいところ恐縮ですが、ご確認のほどよろしくお願いいたします。 |
| お礼 | 何に対するお礼か、具体的に。それで何が良くなったか | 今後ともよろしくお願いいたします。 |
| お詫び | ①お詫び ②何が起きたか（事実） ③原因 ④対応と再発防止 ⑤改めてお詫び。言い訳を先に書かない | 重ねてお詫び申し上げます。 |
| 催促 | 責める言い方をしない。前回の連絡日と内容を示し、「行き違いでしたらご容赦ください」を添える | ご確認いただけますと幸いです。 |
| 断り | 感謝 → 断りの結論 → 理由（簡潔に） → 代案があれば示す | 何卒ご理解いただけますと幸いです。 |
| 日程調整 | 候補を 3 つ以上、曜日つき（例: 11/5（水）14:00〜15:00）。所要時間と場所・会議 URL | ご都合のよい日時をお知らせいただけますと幸いです。 |
| 初めての連絡 | 誰か（会社・名前）→ どうして連絡したか（紹介者・きっかけ）→ 用件 | 突然のご連絡にもかかわらず、お読みいただきありがとうございました。 |

## 5. 返し方

**書くとき**: 件名と本文を 1 つのコードブロックで返す（そのまま貼れるように）。空けた `【】` があれば、その下に一覧で示す。

**直すとき**: 次の 2 つを返す。

1. 直した文面（コードブロック）
2. 変更点の表

```markdown
| 元 | 直し | 理由 |
| --- | --- | --- |
| 資料を拝見させていただきました | 資料を拝見しました | 「拝見」が謙譲語のため、「させていただく」は重複 |
```

- 意味が変わる書き換えはしない。言い回しを丁寧にするだけで、事実・数字・約束の内容は変えない。内容に問題がありそうなとき（期限が過去日、金額の計算が合わない、など）は、直さずに指摘する。
- 元の文面の丁寧さが既に十分なら、無理に変えず「直す所はありません」と伝える。
